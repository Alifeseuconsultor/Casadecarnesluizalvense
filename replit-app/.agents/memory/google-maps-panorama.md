---
name: Google Maps panorama fallback
description: Customer experience preference for Google 360° views when direct embedding is blocked.
---

If Google Maps prevents embedding a panorama, link to the panorama from the storefront in a new tab so the customer can view it without losing the shop page.

**Why:** The user said an external Google Maps view is still worthwhile when the 360° panorama cannot appear directly inside the website.

**How to apply:** Prefer an embedded viewer only when the supplied Google URL and integration support it. Otherwise, add direct panorama links with a clear label and keep store directions separate.
