# Lixeira de consolidação — quarentena reversível

Esta pasta serve para agrupar versões, componentes e dados **candidatos à remoção**, sem apagar nada automaticamente.

- **não** publicar ou importar código desta pasta no aplicativo final;
- manter o histórico das branches originais;
- registrar origem, motivo e decisão em `MANIFESTO.md`;
- excluir somente após a loja final estar testada, publicada e validada pelo responsável.

O backup inicial da vitrine demonstrativa está em `lixeira/vitrine-main-demonstrativa/`. Ele é uma cópia, e os arquivos ativos de `app/` ainda não foram removidos.
